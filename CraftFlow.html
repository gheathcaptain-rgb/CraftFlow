Canlı senkronizasyon kapalıFirebase bağlantısı için index.html içindeki firebaseConfig alanını doldurun.

Canlı senkronizasyonu açmak için:

  1. Firebase Console'da bir Web uygulaması oluşturun ve dosyanın başındaki firebaseConfig nesnesini gerçek proje değerleriyle doldurun.
  2. Authentication → Sign-in method bölümünde Anonymous sağlayıcısını etkinleştirin.
  3. Cloud Firestore'u oluşturup aşağıdaki Rules örneğini yayınlayın.
  4. Dosyayı localhost veya HTTPS üzerinden açın. İki tarayıcı da aynı Firebase projesine bağlanmalıdır.

Kanal ve video kayıtları sırasıyla channels ve videos koleksiyonlarında tutulur. Örnek Rules yalnızca anonim oturum açmış kullanıcılara okuma/yazma izni verir; gerçek üründe erişim kurallarını daraltın.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /channels/{channelId} {
      allow read, write: if request.auth != null;
    }
    match /videos/{videoId} {
      allow read, write: if request.auth != null;
    }
  }
}
